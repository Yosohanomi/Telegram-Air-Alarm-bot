# Telegram-Air-Alarm-bot
Air alarm of your city or region

# 🚨 Бот повітряних тривог

Телеграм-бот для відстеження повітряних тривог та інших загроз в Україні
в реальному часі. Дані беруться з офіційного API `api.ukrainealarm.com`.

---

## 📋 Що вміє бот

- 📍 **Обирати область** — користувач вибирає свою область, і бот її запам'ятовує
- 🔴 **Показувати статус тривоги** — у вибраній області (є тривога / відбій)
- ⚠️ **Розпізнавати тип загрози** — повітряна тривога, артобстріл, хімія тощо
- 🗺 **Показувати всі тривоги** — активні тривоги по всій Україні
- 🔄 **Змінювати область** — якщо користувач переїхав або хоче стежити за іншою
- 📖 **Довідку та інфо** — через команди `/help` та `/info`

---

## 🛠 Технології

- **Python 3.10+**
- **aiogram 3.x** — фреймворк для Telegram-ботів
- **aiohttp** — асинхронні HTTP-запити до API
- **SQLite** — збереження вибору області користувача
- **JSON** — кеш списку областей

Кнопки меню

🔴 Моя область — статус тривоги у вибраній області

🗺 Всі тривоги — активні тривоги по всій Україні

🔄 Змінити область — вибрати іншу область


Як працює кеш
Бот використовує три рівні кешу, щоб не перевантажувати API
(ліміт — ~1 запит на хвилину):

Що кешується	Де зберігається	На скільки
Список областей	regions_cache.json	Назавжди
Статус тривог	Пам'ять	60 секунд
Вибір користувача	bot_users.db (SQLite)	Постійно
Результат: незалежно від кількості користувачів, бот робить
лише 1 запит до API на хвилину.


⚠️ Обмеження API
API api.ukrainealarm.com має жорсткий ліміт — приблизно
1 запит на хвилину на один ключ. Якщо робити запити частіше,
сервер повертає 401 Unauthorized, хоча ключ дійсний.

Саме тому в боті реалізовано кешування. Не видаляй кеш без причини
і не роби прямих запитів до API в обхід бота.

Це означає перевищення ліміту, а не неправильний ключ

Зачекай 60 секунд і спробуй знову
